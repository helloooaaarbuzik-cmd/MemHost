Дата публикации: 22 ноября 2026 г.

## 1. Что это

Mem Host («Программа») — бесплатное приложение для Windows, которое помогает создать локальный сервер Minecraft на платформе Paper и построить мир из нарисованного в приложении рисунка.

Программа не является официальным продуктом Mojang Studios или Microsoft, не связана с ними и не поддерживается ими. Minecraft — товарный знак Mojang Studios.

- **Paper** скачивается с официального сайта PaperMC при создании сервера.
- **Java 25 (Temurin)** скачивается с официального сайта Adoptium либо используется уже установленная в системе.

## 7. Данные

Программа работает локально: сервер, миры, настройки и рисунки хранятся на вашем компьютере (по умолчанию `Desktop\MemHost`). Автор не собирает и не получает эти данные. Сетевые запросы выполняются только для скачивания Paper, Java и списка версий PaperMC.
