# Mem Host

Приложение для Windows, которое собирает Minecraft-сервер Paper **из рисунка**: рисуешь 10×10 (или больше) пикселей на холсте — получается мир такого же размера из блоков. Внутри: мастер создания сервера, установка Java/Paper одной кнопкой, запуск клиента Minecraft сразу на сервер.

## Что умеет

- **Холст Paint**: ЛКМ — рисовать блоком из палитры (22 блока), ПКМ — стереть. Один пиксель = один блок в мире.
- **Меню «Сервер» → «Создать сервер…»**:
  - тип сервера — MemPaint;
  - размер мира — 10, 16, 24, 32, 48, 64 блока;
  - версия Paper — список подтягивается с PaperMC (по умолчанию 26.3);
  - максимум игроков;
  - «Пускать всех (без проверки лицензии)» → `online-mode=false`;
  - Whitelist (ник `MemHost` добавляется в список автоматически);
  - RCON (порт 25575, свой пароль);
  - описание сервера (motd).
- **Создать сервер** сам скачивает Paper нужной версии, ставит портативную Java 25, кладёт плагин, пишет `server.properties`, `eula.txt`, `start.bat`.
- **Запустить / Остановить** — живая консоль сервера в окне, поле для команд (`memhost build`, `op ник`, `stop`).
- **Зайти на сервер** — если сервер не запущен, запускает его и открывает клиент Minecraft с `--quickPlayMultiplayer`, сразу в мир.
- **Применить рисунок** — перестраивает мир без перезапуска (`/memhost build`).

## Требования

| Что | Нужно |
|---|---|
| ОС | Windows 10/11 x64 |
| .NET | **не нужен** — runtime внутри `MemHost.exe` |
| Java | Java 25 (Temurin). Setup скачает её в папку `jdk`, либо возьмёт системную |
| Minecraft | Java Edition **26.3**, установленный в официальном лаунчере (для кнопки «Зайти на сервер») |
| Интернет | при первой установке (Java, Paper ~55 МБ) и при смене версии Paper |
| Права администратора | не нужны, установка портативная |

## Установка через Setup.exe

1. Скачайте из [Releases](../../releases) три файла: `Setup.exe`, `MemHost.exe`, `MemHostPaint.jar`.
2. Положите их в одну папку (например `C:\MemHost`).
3. Запустите `Setup.exe` → «Установить». Он проверит Java 25 (скачает, если нет), Minecraft 26.3, сделает ярлык «Mem Host» на рабочем столе.
4. «Запустить Mem Host» — откроется приложение.

## Как использовать без Setup

Setup не обязателен — он только скачивает Java и делает ярлык. Всё то же делает сама программа при первом запуске.

1. Скачайте `MemHost.exe` и `MemHostPaint.jar`, положите в одну папку.
2. Запустите `MemHost.exe`. Java 25 уже в комплекте? Нет — тогда её скачает само приложение при создании сервера (в `Desktop\MemHost\jdk`).
   Хотите без загрузок — положите папку `jdk` с Java 25 рядом с `MemHost.exe` или установите Java 25 в систему.
3. Меню «Сервер» → «Создать сервер…» → выберите размер, версию, игроков → «Создать».
4. «Запустить» или сразу «Зайти на сервер».

## Куда всё ставится

- Программа: папка, куда распаковали (`MemHost.exe`, `MemHostPaint.jar`, при Setup — ещё `jdk\`).
- Сервер: `%USERPROFILE%\Desktop\MemHost`
  - `paper.jar`, `server.properties`, `eula.txt`, `start.bat`
  - `plugins\MemHostPaint.jar` — плагин, который строит мир
  - `plugins\MemHostPaint\paint.txt` — сам рисунок (материалы, по строке на Z)
  - `memhost.json` — настройки из мастера
  - `jdk\` — портативная Java, если качалась сюда
- Порт сервера: `25565`, RCON (если включён): `25575`.

## Частые вопросы

**Друзья из интернета не заходят.** Нужно открыть порт 25565 на роутере (проброс на этот ПК) и включить в мастере «Пускать всех». `online-mode=true` требует лицензии у всех игроков.

**«Minecraft 26.3 не установлен».** Поставьте версию 26.3 в официальном лаунчере — кнопка «Зайти» ищет её в `%APPDATA%\.minecraft\versions\26.3`.

**Игрок падает в пустоту.** Рисунок пустой — плагин ставит один камень в центр. Нарисуйте хотя бы один блок.

**Хочу больше 64×64.** Размер задаётся списком в мастере; большие миры строятся дольше (блок за блоком на главном потоке).

## Структура репозитория

```
app/      — приложение MemHost (C#, WinForms, .NET 8)
plugin/   — плагин MemHostPaint для Paper (Java 25)
setup/    — установщик Setup (C#, WinForms)
```

Сборка: `dotnet build app\MemHost.csproj` и `dotnet build setup\Setup.csproj`; плагин — `javac`/`jar` против `paper-api` Paper 26.3.
